## Purpose

Избранное хранит постоянные приватные копии выбранных SRT/VTT и предоставляет
быстрый полностью офлайн-доступ к ним с главного экрана после перезапуска.

## ADDED Requirements

### Requirement: Добавление текущего файла в избранное

Система SHALL позволять добавить открытый SRT или WebVTT в избранное с player
screen и SHALL копировать исходное содержимое в приватное хранилище приложения.

#### Scenario: Успешное добавление

- **GIVEN** на player screen открыт корректный файл субтитров
- **WHEN** пользователь нажимает кнопку добавления в избранное
- **THEN** система сохраняет приватную копию файла и metadata
- **THEN** кнопка отображает заполненное состояние избранного
- **THEN** запись появляется на главном экране

#### Scenario: Исходный picker cache удалён

- **GIVEN** файл был успешно добавлен в избранное
- **WHEN** Android удаляет исходную временную cache-копию
- **THEN** избранный файл остаётся доступным из приватной копии

#### Scenario: Недостаточно места

- **GIVEN** приватную копию невозможно записать полностью
- **WHEN** пользователь добавляет файл в избранное
- **THEN** система показывает понятную ошибку
- **THEN** незавершённая запись не появляется в списке избранного

### Requirement: Отсутствие дубликатов по содержимому

Система SHALL идентифицировать избранный файл по hash исходных bytes и не должна
создавать несколько записей для одинакового содержимого.

#### Scenario: Повторное добавление того же содержимого

- **GIVEN** приватная копия файла уже находится в избранном
- **WHEN** пользователь повторно добавляет файл с теми же bytes
- **THEN** система возвращает существующую запись без создания новой копии

### Requirement: Постоянный список на главном экране

Система SHALL показывать сохранённые избранные файлы на главном экране в порядке
от недавно добавленных к более старым.

#### Scenario: Перезапуск приложения

- **GIVEN** пользователь добавил один или несколько файлов в избранное
- **WHEN** приложение полностью перезапускается
- **THEN** главный экран показывает все сохранённые записи

#### Scenario: Устройство offline

- **GIVEN** у устройства отсутствует сетевое подключение
- **WHEN** пользователь просматривает список избранного
- **THEN** список и приватные копии остаются доступными

### Requirement: Открытие избранного файла

Система SHALL открывать избранную приватную копию через существующий parser и
player flow с теми же правилами SRT/WebVTT, overlaps и ошибок.

#### Scenario: Успешное открытие избранного

- **GIVEN** приватная копия существует и содержит корректные субтитры
- **WHEN** пользователь нажимает запись на главном экране
- **THEN** система открывает player screen для этого файла

#### Scenario: Приватная копия отсутствует или повреждена

- **GIVEN** metadata избранного существует, но приватная копия недоступна или не разбирается
- **WHEN** пользователь открывает запись
- **THEN** система показывает понятную ошибку без аварийного завершения
- **THEN** пользователь может удалить неработающую запись

### Requirement: Удаление из избранного

Система SHALL позволять удалить запись из избранного и её приватную копию после
явного подтверждения пользователя.

#### Scenario: Подтверждённое удаление

- **GIVEN** запись находится в избранном
- **WHEN** пользователь подтверждает удаление
- **THEN** запись исчезает с главного экрана
- **THEN** приватная копия удаляется либо помечается для безопасной cleanup

#### Scenario: Отмена удаления

- **WHEN** пользователь отменяет подтверждение удаления
- **THEN** metadata и приватная копия остаются без изменений

### Requirement: Приватность и offline-only поведение

Система SHALL хранить избранное только в приватном application storage и MUST
NOT запрашивать network access или broad filesystem permissions.

#### Scenario: Добавление без дополнительных permissions

- **WHEN** пользователь добавляет уже открытый файл в избранное
- **THEN** система не показывает запрос широкого доступа к файловой системе
- **THEN** данные не отправляются по сети
