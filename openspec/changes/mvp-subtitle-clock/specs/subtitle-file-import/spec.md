## ADDED Requirements

### Requirement: Выбор локального файла субтитров

Система SHALL позволять пользователю выбрать локальный файл SRT или WebVTT через
системный Android document picker без запроса широкого доступа к хранилищу.

#### Scenario: Успешный выбор SRT

- **WHEN** пользователь выбирает доступный файл с расширением `.srt`
- **THEN** система читает файл, разбирает cues и открывает player screen

#### Scenario: Успешный выбор WebVTT

- **WHEN** пользователь выбирает доступный файл с расширением `.vtt`
- **THEN** система читает файл, разбирает cues и открывает player screen

### Requirement: Ошибки импорта

Система SHALL преобразовывать ошибки чтения и парсинга в понятное сообщение и не
должна завершать приложение аварийно.

#### Scenario: Повреждённый файл

- **WHEN** выбранный файл содержит недопустимый синтаксис субтитров
- **THEN** система показывает ошибку и оставляет пользователю возможность выбрать другой файл

#### Scenario: Неподдерживаемый формат

- **WHEN** пользователь пытается открыть неподдерживаемый формат
- **THEN** система сообщает, что MVP поддерживает только SRT и WebVTT

### Requirement: Работа без сети

Система SHALL выполнять выбор, разбор и воспроизведение субтитров без сетевого подключения.

#### Scenario: Устройство offline

- **GIVEN** у устройства отсутствует сетевое подключение
- **WHEN** пользователь открывает корректный локальный файл
- **THEN** все функции MVP остаются доступными
